# Root-level audio source records

These eight files are original procedural synthesis generated by project scripts. The scripts create samples from oscillator/noise calculations and do not read third-party recordings, samples, or music.

## Sample-room effects

| File | Source and use |
| --- | --- |
| `click.wav` | Generated by `tools/build_sample_art.py` as a short decaying sine/noise click. Used by `AudioManager.play_dialogue_advance()` and the sample-room interaction. |
| `scrape.wav` | Generated by `tools/build_sample_art.py` as a decaying low-frequency sine/noise effect. Explicitly triggered by `levels/ch0_tanglau/sample_room.gd`. |
| `step.wav` | Generated by `tools/build_sample_art.py` as a short decaying sine/noise effect. No direct `play_effect("step")` call was found in the current source scan; `AudioManager.play_effect()` can load it by name. |
| `latch.wav` | Generated by `tools/build_sample_art.py` as a short decaying sine/noise effect. No direct `play_effect("latch")` call was found in the current source scan; `AudioManager.play_effect()` can load it by name. |
