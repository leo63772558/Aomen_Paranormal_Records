# Chapter 4 bus and Chapter 0 demo audio sources

This folder contains two groups of sound assets. The Chapter 4 bus set listed first is original procedural synthesis from `tools/build_bus_ch4_assets.py`; the remaining Chapter 0 cues have separate provenance records or an explicitly unresolved source status below.

## Chapter 4 bus assets

| File | Use |
| --- | --- |
| `bridge_bus_ambience.wav` | Looping bus motor, wind, and road joints |
| `bus_bell_chime.wav` | Two-tone stop bell |
| `bus_screamer_glitch.wav` | Dissonant wrong-judgment stinger |
| `mannequin_snap.wav` | Short joint-crack sound for the passenger turn |
| `window_slap.wav` | Repeated low-frequency hand impacts and glass-like ticks |
| `blood_boil.wav` | Bubbling anomaly loop |
| `bus_crash_cinematic.wav` | Impact, metal rattle, sand roll, and sea fade for the bus crash |

These seven files are original procedural synthesis; no third-party recordings, samples, or music are included in this group. The generator is the source of record.

They are preserved only inside `tools/recovery/audio_provenance_unverified_20261117.zip` for audit and are not intended for the game export. Their source and license remain unknown, so they must not be redistributed.
