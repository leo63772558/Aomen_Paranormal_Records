# Chapter 4 bus and Chapter 0 demo audio sources

This folder contains two groups of sound assets. The Chapter 4 bus set listed first is original procedural synthesis from `tools/build_bus_ch4_assets.py`; the remaining Chapter 0 cues have separate provenance records or an explicitly unresolved source status below.

## Chapter 4 bus assets

| File | Use |
| --- | --- |
| `bridge_bus_ambience.wav` | Looping bus motor, wind, and road joints |
| `bus_bell_chime.wav` | Two-tone stop bell |
| `bus_screamer_glitch.wav` | Dissonant wrong-judgment stinger |
| `mannequin_snap.wav` | Short joint-crack sound for the passenger turn |
| `window_slap.wav` | Repeated low-frequency hand impacts and glass-like ticks |
| `blood_boil.wav` | Bubbling anomaly loop |
| `bus_crash_cinematic.wav` | Impact, metal rattle, sand roll, and sea fade for the bus crash |

These seven files are original procedural synthesis; no third-party recordings, samples, or music are included in this group. The generator is the source of record.

## Chapter 0 demo cues

The following eight cues use or adapt credited CC0 recordings and project synthesis. Author, source, license and usage details are in `../recorded/SOURCE_LICENSE.md`, under “Demo 026”:

- `recording_fragment_026.wav`
- `hall_wail_026.wav`
- `pit_drop_026.wav`
- `door_approach_026.wav`
- `power_failure_026.wav`
- `capture_hit_026.wav`
- `capture_rush_026.wav`
- `oil_drops_026.wav`
- `scare_bulb_pop.wav`, `scare_door_bang.wav`, `scare_extra_step.wav`, `scare_whisper_ear.wav`, `scare_pipe_scrape.wav`, `scare_radio_static.wav`, `electric_arc_blast.wav`, `boss_roar_impact.wav` (generated by `tools/build_expanded_audio_20261121.py`)

The project-made replacement `chase_urgent_122.wav` is used by the registered chase music key, and `jumpscare_shriek_122.wav` is used by the registered stinger key. Both are documented procedural synthesis from `tools/build_audio_replacements_122.py`; see their adjacent `.source.md` records and `docs/audio_generation_122.md`. The unverified legacy files `chase_urgent_026.wav` and `jumpscare_shriek_026.wav` have been removed from the game asset tree. They are preserved only inside `tools/recovery/audio_provenance_unverified_20261117.zip` for audit and are not intended for the game export. Their source and license remain unknown, so they must not be redistributed.

Background checks use dummy audio. They confirm loading and trigger paths only, not mix, loudness, loop quality, listening quality, or fear response.
