# 中文字体来源与开源许可说明（`assets/fonts/`）

- **字体文件**：`noto_serif_sc_subset.ttf`
- **原始字体**：Google Fonts *Noto Serif SC*（思源宋体简体）可变字体 `NotoSerifSC[wght].ttf`，实例化字重 `wght=500` 后按本工程全量 UI/剧情用字子集化生成。
- **来源地址**：`https://github.com/google/fonts/tree/main/ofl/notoserifsc`
- **开源许可**：SIL Open Font License 1.1（完整协议全文见同目录 `OFL.txt`），允许商业与非商业游戏分发、子集嵌入与网页加载。
- **用途**：用于《澳诡实录》Web/HTML5 网页试玩版与桌面端中文宋体排版一致性渲染，解决浏览器无法读取本地 `SystemFont` 的问题。
