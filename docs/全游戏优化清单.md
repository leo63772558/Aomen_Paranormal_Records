## 第三批 · 全游戏统一验收

- [ ] **删文字。** 从正式新档记录每次强制弹窗。优先删掉重复描述画面、全文复述任务和提前公布谜底的句子。需要重看的证据放回相册或实物原处。
- [ ] **收界面。** 正式标题页直接提供新游戏、继续、设置和退出；样板保留独立入口。背包打开即可看清当前选中物的名称、图像与用途，返回时不会误触世界。
- [ ] **让惊吓产生选择。** 每场主要威胁标出第一次预兆、玩家可做的动作、敌人反馈和失败后的最近重试点。对扑脸逐帧看接近、遮挡与恢复；回到游戏时危险和控制状态必须一致。
- [ ] **逐房查比例和通行。** 以 005 样板对照人物、床、门、桌和台灯照片；核对八向脚底、握灯点、道具动作。对变化的门、床、铁栏和盖板分别检查前后状态。
- [ ] **查画面与声音。** 在支持的窗口尺寸检查正文、竖排选项、返回提示和实际点击范围；检查阀门、水流、木门、金属、脚步的触发与暂停恢复，再单独做耳机听感验收。
- [ ] **盲玩后再打包。** 找三位没看过攻略的人，分别从正式开头和第五章正常检查点开始。记录第一次停住的位置、当时以为要做什么、画面漏传了什么信息；两人卡在同一处就回到该场景改。最后用隔离存档跑完整主线、三结局及关键操作中断后的读档。

第一轮试玩先看三件事：资料柜关上后会往哪走、错转阀门后会看哪里、救出嘉敏后是否知道故事已经收束。这三个瞬间最能检验环境、机关与叙事有没有接起来。
