# 唐楼样板素材与参考

当前 005 样板的背景、家具、成年比例人物、信箱和人物头像由内置 imagegen 生成后复制入项目。实际路径、完整提示词和接入方式见 [003 素材记录](美术生成_003.md)、[004 素材记录](美术生成_004.md)、[005 持手电人物](美术生成_005.md)。标题、文字窗皮肤、灯光纹理与部分短音效有项目内可编辑制作源。衣柜进出使用 qubodup / Iwan Gabovitch 的 [Door Open, Door Close Set](https://opengameart.org/content/door-open-door-close-set)，2026-11-09 核对来源页 CC0 并下载；两条原始 OGG 及具体文件映射见 `assets/audio/qubodup/SOURCE_LICENSE.md`。没有提取或使用参考游戏的角色、地图、UI 图像、音频或游戏文件。早期程序绘制版本保留为制作历史，不代表当前活动素材。

用户 2026 年 11 月 9 日指定《野比大雄的生化危机》为画风方向，参考截图只用于观察老式 RPG 的室内透视、像素层次与表现方法：

- [另一截图所在页面](https://dl.3dmgame.com/pc/91270.html)，参考图地址：https://img.3dmgame.com/uploads/allimg/170107/321-1F10GA246.jpg

参考图片位于 `docs/review_sources/`，有 `.gdignore` 隔离；正式导出仍需另设排除规则并核对包清单。本轮没有创建发行包。

Godot 从[官方 Windows 下载入口](https://godotengine.org/download/windows/)核对版本，二进制从官方 `godotengine/godot-builds` 的 `4.7.2-stable` release 下载，独立放在 tools 内。Godot 为 MIT 许可，正式打包引擎时需带齐其许可与第三方声明。
