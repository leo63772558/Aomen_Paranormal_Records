# 试玩篇 026 美术与参考

本轮以 005 二维恐怖 RPG 样板为材质和角色比例基准。使用内置 imagegen 制作下列位图，标题字样、道具操作、碰撞、光效、分帧和界面由 Godot 处理。场景图与证据照片属于虚构的游戏画面。

- `assets/ui/menu_macau_026.png`。以原大三巴街场景的纹理为参考。雨后大三巴牌坊和石阶占右侧，葡式黑白波浪石仔路和蓝白砖牌在前景，左侧留暗部给独立标题和菜单。
- `assets/tilesets/hk_work_026.png`、`hk_home_026.png`、`bridge_bus_026.png`。同一套 2D 笔触，工作间和家中留出平面通路，工作台、照片和攻略桌靠墙。车内以大文的参考造型表现两位旅客，桥塔从窗外可见，画面下部留字幕区。
- `assets/props/room304_old_photo_026.png`。沿用旧照的窗格、花砖和铁床，增加四位合照人物，并让床后的半开木门、门下百叶同时看得清。
- `assets/props/demo_props_026.png`。透明十二格，含陶瓷芯、桥片、湿检修签、方轴、握柄、组装手柄、碎石、录音机、工单、拓记、旧百叶和一簇骨骸。它们各自对应摆放点和机关用途。
- `assets/props/power_panel_026.png`、`service_latch_026.png`、`crypt_door_clip_026.png`。分别是三组仪表和绝缘接点、带方孔的铁门偏心轮、横跨木门与石门框的实物卡扣。`maintenance_open_026.png` 保留通道原材质并呈现铁门打开后的入口。
- `assets/tilesets/bunker_lock_bg_026.png` 与 `assets/props/bunker_lock_parts_026.png`。去掉背景内烘焙的链条和锁，只保留门扣和右侧托钩。锁身、锁梁和链条独立成图，以便挂链、转锁和移链。
- `assets/tilesets/ammo_floor_026.png`。使用原子弹房石墙、管道、灯和南侧出入口风格，生成连续地面。五排坑口由既有图块单独摆放，通道与碰撞在同一组几何中设置。
- `assets/characters/tanglau_stalker_026.png`、`bunker_family_026.png`、`dawen_throw_026.png`。唐楼黑影为六帧潮湿长衣的侧行；防空洞分别制作父亲、母亲、女儿的姿态，使用不同尺寸和移动速度；大文抛石使用准备和出手帧。
- `assets/characters/priest_lunge_026.png`、`bunker_family_lunge_026.png`。各为 3×2 的六格连续动作，人物保持同一造型，依次抬头、前倾、伸手、扑近、撞到视野、贴脸。Godot 在第五帧触发冲击音，之后切黑并进入重试。
