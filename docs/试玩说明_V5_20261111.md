# V5 试玩说明 · 2026-11-13

叙事统一采用用户确认的“阿豪同行、嘉敏沿途求生留痕”主线。建议双击项目根目录的 `从头开始试玩.cmd`，它创建独立新进度，旧存档保留。旧档已经越过唐楼时不会强制重演阿豪段。

当前可玩范围：香港准备 → 澳门唐楼与阿豪逃生 → 304 → 地宫 → 松山防空洞 → 肉铺杆秤与物证 → 随机末班车 → 黑沙鞋痕、救生站设备与沿海工事图 → 沿海维护通道 → 井下维护平台 → 闸室 → 淤泥岔口。闸室先对照盐线、地栅沉积、检修盖与粉笔痕，核验左拱；淤泥岔口再对照无名示意图、封闭闸门、坍塌支路与地栅，最后到中央拱口核对擦痕。现场手札会记录结论。可沿南侧通道原路返回闸室、维护平台与黑沙。地图在中央拱道下个转弯前中断；更深处、赌场地基救援与结局尚未制作，旧痕迹也不能证明嘉敏此刻仍在前方。

- WASD 八向移动，Shift 奔跑，鼠标独立照看方向，E 交互，Esc 暂停或收起面板。
- Q / Tab 只在手机仍随身且场景允许时查看嘉敏手机；手机留在 304 后，后续沿海区域不提供手机信息。B 打开证据背包；J 按场景打开调查手札或对应复查内容。
- 机关用鼠标操作：按住拖动、旋转、提盖、侧拉；放开后保留或回弹，不用在说明文字上猜点击位置。
- 末班车发现异常需要先拉铃，再退后门；正常从前门下车，连续五次。单独拉铃不算通过。
- 黑沙有潮水与白影；干带、石阶和高地可退回，资料不会被浪冲走。车灯三档有不同实际效果。沿海维护通道需核对四处痕迹后才能下井；下层排水口与锈闸门封住退路，粉笔箭头和布丝指向右侧窄道，E 调查，J 查看现场手札。
- 淤泥岔口：核对图纸、右侧闸门、左侧坍塌与地栅淤泥后，再调查中央拱口。被封闸门、坍塌和湿地边缘均有实体碰撞；中央干路核验后，可沿南侧通道返回。图纸没有真实地名，地下连接属于本作虚构关卡。

标题的两个独立入口分别体验阿豪逃生与固定车厢机关样板，返回时恢复进入前的正式状态。固定样板与正式随机末班车规则分开。

后台自动检查已静音并使用 test 配置；淤泥岔口覆盖证据前置、暂停冻结、实体碰撞、场景往返及检查点数据校验。当前环境拒绝创建隐藏渲染桌面，新增场景未完成实机画面复核；存档目录也不可写，因此本次只做了内存中的检查点解码校验，没有验证磁盘写入与重启回读。实际恐怖感、谜题难度、动作观感与听感仍需真人试玩。现有 026 好友压缩包是旧版本，本次没有将其冒充新版。
